[Markdown](https://markdown.com.cn/basic-syntax/index.html) is a lightweight markup language with concise typographic syntax, allowing people to focus more on content rather than formatting. It uses a plain text format that is easy to read and write for creating documents, can be mixed with HTML, and can be exported to HTML, PDF, and its own .md format files. Because of its conciseness, efficiency, readability, and writability, Markdown is widely used, such as on [GitHub](https://github.com), [Wikipedia](zh.wikipedia.org), and [Jianshu](https://www.jianshu.com/).

# Common Markdown Syntax

- **Bold** – Bold (`**bold**` or `__bold__`)  
- *Italic* – Italic (`*italic*` or `_italic_`)  
- > Blockquote – Blockquotes (`> blockquote`)  
- 1. Ordered – Ordered Lists (`1. item`, `2. item`)  
- - Unordered – Unordered Lists (`- item`, `* item`, `+ item`)  
- `Inline Code` – Inline Code (`` `code` ``)  
- ```  
  Fenced Code Block  
  ``` 

- Fenced Code Blocks (`Code`)  
- --- – Horizontal Rules (`---`, `***`, `___`)  
- [Link](https://example.com) – Links (`[text](url)`)  
- Images (`![alt](url)`)  
- | col1 | col2 | – Tables (`| col1 | col2 |`)  
- - [x] Task – Task Lists (`- [ ]` and `- [x]`)  
- ~~Strikethrough~~ – Strikethrough (`~~strikethrough~~`)  
- 😄 – Emoji (`:smile:`) 

# Markdown Heading Syntax

To create a heading, add hash signs (`#`) before a word or phrase. The number of `#` indicates the heading level. For example, adding three `#` creates a third‑level heading (`<h3>`) (e.g., `### My Header`).

| Markdown Syntax            | HTML                       | Preview        |
| :------------------------- | :------------------------- | :------------- |
| `# Heading level 1`        | `<h1>Heading level 1</h1>` | Heading level 1 |
| `## Heading level 2`       | `<h2>Heading level 2</h2>` | Heading level 2 |
| `### Heading level 3`      | `<h3>Heading level 3</h3>` | Heading level 3 |
| `#### Heading level 4`     | `<h4>Heading level 4</h4>` | Heading level 4 |
| `##### Heading level 5`    | `<h5>Heading level 5</h5>` | Heading level 5 |
| `###### Heading level 6`   | `<h6>Heading level 6</h6>` | Heading level 6 |

## Alternate Syntax

You can also add any number of `=` signs below the text to identify a first‑level heading, or `-` signs for a second‑level heading.

| Markdown Syntax                       | HTML                       | Preview        |
| :----------------------------------- | :------------------------- | :------------- |
| `Heading level 1===============`     | `<h1>Heading level 1</h1>` | Heading level 1 |
| `Heading level 2---------------`     | `<h2>Heading level 2</h2>` | Heading level 2 |

## Best Practices

Different Markdown applications handle spaces between `#` and heading text inconsistently. For compatibility, always separate the `#` and the heading with a single space.

| ✅ Do this            | ❌ Don't do this     |
| :------------------- | :------------------ |
| `# Here's a Heading` | `#Here's a Heading` |

# Markdown Paragraphs

To create paragraphs, use a blank line to separate one or more lines of text.

| Markdown Syntax                                                 | HTML                                                         | Preview                                                      |
| :-------------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `I really like using Markdown.I think I'll use it to format all of my documents from now on.` | `<p>I really like using Markdown.</p><p>I think I'll use it to format all of my documents from now on.</p>` | I really like using Markdown.I think I'll use it to format all of my documents from now on. |

## Best Practices for Paragraph Usage

Do not indent paragraphs with spaces or tabs.

| ✅ Do this                                                    | ❌ Don't do this                                              |
| :----------------------------------------------------------- | :----------------------------------------------------------- |
| `Don't put tabs or spaces in front of your paragraphs.Keep lines left-aligned like this.` | `  This can result in unexpected formatting problems. Don't add tabs or spaces in front of paragraphs.` |

# Markdown Emphasis Syntax

Emphasize the importance of text by making it bold or italic.

## Bold

To bold text, add two asterisks or underscores before and after a word or phrase. To bold the middle part of a word or phrase for emphasis, add two asterisks on both sides of the part to be bolded.

| Markdown Syntax                 | HTML                                      | Preview                    |
| :------------------------------ | :---------------------------------------- | :------------------------- |
| `I just love **bold text**.`    | `I just love <strong>bold text</strong>.` | I just love **bold text**. |
| `I just love __bold text__.`    | `I just love <strong>bold text</strong>.` | I just love **bold text**. |
| `Love**is**bold`                | `Love<strong>is</strong>bold`             | Love**is**bold             |

### Best Practices for Bold

Markdown applications are inconsistent in how they handle underscores in the middle of words or phrases. For compatibility, use asterisks to bold the middle part of a word or phrase.

| ✅ Do this        | ❌ Don't do this  |
| :--------------- | :--------------- |
| `Love**is**bold` | `Love__is__bold` |

## Italic

To italicize text, add one asterisk or underscore before and after a word or phrase. To italicize the middle part of a word, add one asterisk before and after the letters without spaces.

| Markdown Syntax                           | HTML                                          | Preview                              |
| :---------------------------------------- | :-------------------------------------------- | :----------------------------------- |
| `Italicized text is the *cat's meow*.`    | `Italicized text is the <em>cat's meow</em>.` | Italicized text is the *cat’s meow*. |
| `Italicized text is the _cat's meow_.`    | `Italicized text is the <em>cat's meow</em>.` | Italicized text is the *cat’s meow*. |
| `A*cat*meow`                              | `A<em>cat</em>meow`                           | A*cat*meow                           |

### Best Practices for Italic

To emphasize text with both bold and italics, add three asterisks or underscores before and after a word or phrase. To bold and italicize the middle part of a word or phrase, add three asterisks before and after the part to be emphasized without spaces.

| ✅ Do this    | ❌ Don't do this |
| :----------- | :-------------- |
| `A*cat*meow` | `A_cat_meow`    |

## Bold and Italic

To emphasize text with both bold and italics, add three asterisks or underscores before and after a word or phrase. To bold and italicize the middle part of a word or phrase, add three asterisks before and after the part to be emphasized without spaces.

| Markdown Syntax                              | HTML                                                         | Preview                                  |
| :------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------- |
| `This text is ***really important***.`       | `This text is <strong><em>really important</em></strong>.`   | This text is ***really important***.     |
| `This text is ___really important___.`       | `This text is <strong><em>really important</em></strong>.`   | This text is ***really important***.     |
| `This text is __*really important*__.`       | `This text is <strong><em>really important</em></strong>.`   | This text is ***really important***.     |
| `This text is **_really important_**.`       | `This text is <strong><em>really important</em></strong>.`   | This text is ***really important***.     |
| `This is really***very***important text.`    | `This is really<strong><em>very</em></strong>important text.` | This is really***very***important text.  |

### Best Practices for Bold and Italic

Markdown applications are inconsistent in how they handle underscores in the middle of words or phrases. For compatibility, use asterisks to bold and italicize the middle part of a word or phrase to show importance.

| ✅ Do this                                 | ❌ Don't do this                           |
| :---------------------------------------- | :---------------------------------------- |
| `This is really***very***important text.` | `This is really___very___important text.` |
